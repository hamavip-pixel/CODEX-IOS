# HAMACODEX.xcframework

An iOS dynamic framework generated by **Kodeing — dylib foundry**, packaged as an
XCFramework with a device slice and a simulator slice.

| Setting | Value |
| --- | --- |
| Language | C++ |
| Slices | `ios-arm64` (device), `ios-arm64-simulator` (simulator) |
| Minimum iOS | undefined |
| Configuration | Release |
| Bundle identifier | `com.hama.codex` |
| Install name | `@rpath/HAMACODEX.framework/HAMACODEX` |
| Current / compatibility version | 1.0.0 / 1.0.0 |
| Default symbol visibility | hidden |
| Exported symbols | 6 (see `exports.txt`) |

Requires a Mac with **Xcode** installed: the Command Line Tools alone don't include the iOS SDKs.
If `xcrun --sdk iphoneos --show-sdk-path` fails, run `sudo xcode-select -s /Applications/Xcode.app`.

## Build

```sh
./build.sh        # build both slices, bundle the XCFramework, run the test client
make              # or use make
make test         # needs a booted simulator (open -a Simulator)
make info
```

CMake also works. `CMakeLists.txt` has the commands to build one tree per SDK and merge them.

## What the build runs

```sh
IOS_SDK="$(xcrun --sdk iphoneos --show-sdk-path)" \
    SIM_SDK="$(xcrun --sdk iphonesimulator --show-sdk-path)"
mkdir -p build/iphoneos/HAMACODEX.framework/Headers build/iphoneos/HAMACODEX.framework/Modules
clang++ -dynamiclib \
    -arch arm64 -miphoneos-version-min=undefined \
    -isysroot "${IOS_SDK}" \
    -std=c++17 -O2 -DNDEBUG -Wall -Wextra -fvisibility=hidden \
    -Iinclude \
    -install_name @rpath/HAMACODEX.framework/HAMACODEX \
    -current_version 1.0.0 -compatibility_version 1.0.0 \
    -Wl,-exported_symbols_list,exports.txt \
    src/HAMACODEX.cpp -o build/iphoneos/HAMACODEX.framework/HAMACODEX
cp include/HAMACODEX.h build/iphoneos/HAMACODEX.framework/Headers/ \
    && cp framework/module.modulemap build/iphoneos/HAMACODEX.framework/Modules/ \
    && cp framework/Info.plist build/iphoneos/HAMACODEX.framework/Info.plist \
    && plutil -insert CFBundleSupportedPlatforms -json '["iPhoneOS"]' build/iphoneos/HAMACODEX.framework/Info.plist
codesign --force --sign - build/iphoneos/HAMACODEX.framework
mkdir -p build/iphonesimulator/HAMACODEX.framework/Headers build/iphonesimulator/HAMACODEX.framework/Modules
clang++ -dynamiclib \
    -arch arm64 -mios-simulator-version-min=undefined \
    -isysroot "${SIM_SDK}" \
    -std=c++17 -O2 -DNDEBUG -Wall -Wextra -fvisibility=hidden \
    -Iinclude \
    -install_name @rpath/HAMACODEX.framework/HAMACODEX \
    -current_version 1.0.0 -compatibility_version 1.0.0 \
    -Wl,-exported_symbols_list,exports.txt \
    src/HAMACODEX.cpp -o build/iphonesimulator/HAMACODEX.framework/HAMACODEX
cp include/HAMACODEX.h build/iphonesimulator/HAMACODEX.framework/Headers/ \
    && cp framework/module.modulemap build/iphonesimulator/HAMACODEX.framework/Modules/ \
    && cp framework/Info.plist build/iphonesimulator/HAMACODEX.framework/Info.plist \
    && plutil -insert CFBundleSupportedPlatforms -json '["iPhoneSimulator"]' build/iphonesimulator/HAMACODEX.framework/Info.plist
codesign --force --sign - build/iphonesimulator/HAMACODEX.framework
rm -rf build/HAMACODEX.xcframework \
    && xcodebuild -create-xcframework \
    -framework build/iphoneos/HAMACODEX.framework \
    -framework build/iphonesimulator/HAMACODEX.framework \
    -output build/HAMACODEX.xcframework
```

## Test it in the Simulator

```sh
clang++ -arch arm64 -mios-simulator-version-min=undefined \
    -isysroot "${SIM_SDK}" \
    -std=c++17 -Iinclude -F build/iphonesimulator test/main.cpp \
    -framework HAMACODEX -Wl,-rpath,@executable_path/iphonesimulator \
    -o build/HAMACODEX_test
xcrun simctl spawn booted "${PWD}/build/HAMACODEX_test"
```

## Using the framework in an app

**Xcode** — drag `build/HAMACODEX.xcframework` into your project. Under the app target's *General → Frameworks,
Libraries, and Embedded Content*, set it to **Embed & Sign**. Xcode signs it with your identity
when it copies it into `MyApp.app/Frameworks/`.

**Swift**

```swift
import HAMACODEX
print(HAMACODEX_add(2, 3))
```

**C / Objective-C** — `#import <HAMACODEX/HAMACODEX.h>` or `@import HAMACODEX;`

**Swift Package Manager** — zip it and publish it as a binary target:

```sh
ditto -c -k --sequesterRsrc --keepParent build/HAMACODEX.xcframework build/HAMACODEX.xcframework.zip
swift package compute-checksum build/HAMACODEX.xcframework.zip
```

```swift
.binaryTarget(name: "HAMACODEX", url: "https://example.com/HAMACODEX.xcframework.zip", checksum: "<checksum>")
// or, inside the same repo:
.binaryTarget(name: "HAMACODEX", path: "HAMACODEX.xcframework")
```

**Sign for distribution** — `codesign --timestamp --sign "Apple Distribution: …" build/HAMACODEX.xcframework`
lets Xcode check where the framework came from.

App Store apps can't ship a bare `.dylib`. Dynamic code has to live in an embedded `.framework`,
which is why this project builds one.
